# 🎬 VideomakerI.A - AI Video Studio (Image-to-Video & Text-to-Video)

Estúdio portátil e web de geração de vídeos cinematográficos com Inteligência Artificial, projetado com modelos de ponta (**ByteDance Seedance 2.5**, **Kling AI 1.5**, **Minimax Hailuo** e **Luma Dream Machine**).

---

## 🚀 Como Iniciar no Computador (Host Local)

### Método 1: Executável Portátil (1 Clique)
Basta dar um duplo clique no arquivo:
👉 `iniciar.bat`

Ele abrirá automaticamente o navegador no endereço:
🌐 **`http://localhost:3000`**

### Método 2: Via Terminal
```powershell
cd C:\Users\Lenovo\Documents\antigravity\VideomakerI.A
npx serve . -l 3000
```

---

## 📱 Como Usar no Celular e Instalar o App (PWA 24/7 na Vercel)

1. Suba o projeto para o seu GitHub:
   ```powershell
   git init
   git add .
   git commit -m "feat: VideomakerI.A inicial com suporte a PWA e galeria de prompts"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/VideomakerIA.git
   git push -u origin main
   ```
2. Conecte o repositório na **Vercel** (deploy automático em 30 segundos).
3. Abra o link gerado pela Vercel no **Google Chrome do celular**.
4. Toque no botão **"Instalar Aplicativo"** ou nos 3 pontinhos do Chrome ➔ **"Instalar app / Adicionar à tela inicial"**.

## ✨ Recursos Inclusos no VideomakerI.A
- **📸 Upload Inteligente:** Suporte a fotos de pessoas, objetos ou cenários com verificação de enquadramento.
- ** Galeria com Mini-Vídeos de Exemplo:** Veja na prática como o vídeo fica passando o mouse nos mini-vídeos dos presets antes de gerar.
- **🤖 Suporte Multi-Modelos:** Seedance 2.5 (ByteDance), Kling 1.5, Minimax Hailuo e Luma Dream Machine.
- **🎯 Tags Rápidas de Câmera:** Adicione efeitos de *Slow Motion*, *Dolly-in*, *Giro 360°*, *Vento Natural* e *Golden Hour* com 1 toque.
- **🎞️ Player Cinematográfico:** Reprodução contínua, tela cheia e download direto do arquivo `.mp4`.
- **🕒 Histórico de Vídeos:** Guarda seus vídeos gerados durante a sessão.
